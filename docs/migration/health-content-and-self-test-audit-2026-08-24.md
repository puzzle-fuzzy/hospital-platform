# 健康内容与自测迁移审计（2026-08-24）

## 状态

当前状态：`closed-awaiting-clinical-evidence`。

本轮只对照旧小程序的健康百科、健康自测、BMI 和血压计算器实现，复核新项目已有的健康知识
domain/service/repository/importer 边界。没有导入旧正文、没有注册健康知识 API、没有新增患者端页面、
没有修改旧 Python 服务、数据库、Redis 或线上配置。

本文的结论优先于“页面能渲染”或“本地计算有结果”：医疗内容和评分规则必须先有来源、版本、审核责任
和撤回机制，才能进入患者端。

## 1. 旧端事实基线

### 1.1 健康自测问卷

旧端来源：

- `G:\\fuck\\hospital\\hospital-app\\src\\jsonData\\selfTestConfig.ts`；
- `G:\\fuck\\hospital\\hospital-app\\src\\api\\modules\\selfTest.ts`。

旧配置包含动脉血管、2 型糖尿病、肺功能、BMI、心脏、心理年龄、痴呆和心理压力等多组题目，
题目选项带有分值，结果通过本地配置的区间映射为“低风险/中风险/高风险”等等级。旧 HTTP 类型允许
`Record<string, any>` 答案、可选题目字段和多种后端字段别名，接口响应只约定 `level/description/tips`，
没有把题库版本、评分版本、来源、适用人群、审核人和生效窗口作为业务事实。

因此不能把旧配置直接复制到新 TypeScript 项目，也不能把一个通用 `assessment` 接口当成所有自测的
统一评分器。题目、答案范围、必答项、分值、结果区间和免责声明必须属于同一份不可变问卷版本。

### 1.2 BMI 计算器

旧端页面在本地使用 `体重(kg) / 身高(m)^2` 计算 BMI，展示一位小数；代码分层使用 `<18.5`、
`18.5~<24`、`24~<28`、`28~<35`、`35~<40` 和 `>=40`，但页面参考表同时展示 WHO、亚洲和中国的
另一组区间，且注释明确写有“示例，数值可按规范微调”。输入只做非空式校验，没有明确成人适用人群、
身高/体重合理范围、单位精度或特殊人群排除。

这代表旧页面的计算分类、参考表和解释文字不是一个可追溯的规则版本。新端不能以旧页面结果或静态表格
作为临床标准，也不能把“数值算出来”解释为风险评估完成。

### 1.3 血压计算器

旧端页面输入年龄、性别、收缩压和舒张压；年龄和性别只用于查找页面内的 16～55 岁参考均值表，
不参与主要分类。分类代码把一次输入按低血压、正常、偏高、一级高血压和二级高血压展示，页面还写有
“1998 年标准”。输入同样只有非空式校验，没有测量条件、重复测量、异常组合、适用人群和危险值提示的
版本化规则。

这不能直接迁移为诊断或临床分级能力；一次家庭输入不能生成确诊、处方或治疗建议。

## 3. 业务决策与不可绕过的边界

1. 健康百科是“已审核只读内容”，自测是“版本化问卷与评分规则”，BMI/血压计算器是“规则版本化的
   非诊断性参考计算”；三者不能共用一个成功状态或一个宽泛的 `assessment` 请求。
2. 旧端 `symptoms_ids`、整数 ID、`any` 答案和旧页面阈值只作为迁移输入事实，不直接成为新公共 contract。
3. 没有真实来源、脱敏、适用人群、审核责任和撤回策略时，不导入正文、不导入评分配置、不注册患者路由，
   不用默认数据填充页面，不用旧接口转发制造“已迁移”。
4. 如果将来只开放 BMI/血压本地参考计算，也必须在构建产物中固定 `ruleSetVersion`，只接收归一化数值，
   明确不适用人群，显示固定免责声明，并禁止保存到患者、报告、随访或风险评估记录。
5. 任何高风险提示都必须来自审核后的规则文本；不能由前端根据数值临时拼接急救、诊断或用药结论。

## 4. 允许进入实现的前置材料

### 健康百科

- 旧库脱敏导出、数量/关系/孤儿引用报告和旧 ID 到新 opaque ID 的映射；
- 来源、内容版本、审核人引用、审核时间、固定免责声明和有效窗口；
- staging 的 draft → published、撤回、重新发布和缓存失效证据；
- 列表、疾病详情、药品详情的人工字段复核和真机展示证据。

### 健康自测

- 每一套问卷的独立 `assessmentVersion`；
- 题目 ID、答案类型、答案范围、必答项、分值和结果区间的不可变快照；
- 临床/业务负责人确认记录、结果文本和适用人群；
- 版本撤回、历史结果解释、幂等提交和隐私保留策略；
- 不能把筛查提示写成诊断结论的产品与医学复核。

### BMI/血压参考计算

- 权威来源、适用人群、规则边界和规则版本；
- 身高/体重/血压的范围、精度、单位、异常组合和重复测量策略；
- 参考分类、危险值文案和就医提示的审核版本；
- 页面不联网、不保存敏感结果、不产出医疗结论的验收证据。

## 5. 当前验证与下一步

本轮已完成旧端文件、接口、页面和新端边界的静态对照；已确认：
