## 维护

- 新能力同步契约、架构、日志事件和对应验收说明；不把缺少业务证据写成已完成。
- 文档移动或删除前检查源码、脚本、JSON 清单、相对链接及外部交付引用，再执行 `pnpm docs:audit` 和受影响的专项审计。
- 新增 Provider 接收记录保留稳定 `documentId`、真实来源指纹及本页入口；缺失材料按缺失记录。
- 真实配置、凭据、生产导出、运行包和本机诊断留在约定的受控位置，源码文档只登记用途和脱敏证据。
- 目录分类、归档条件与本轮待办统一见[文档治理](治理/文档治理.md)。
