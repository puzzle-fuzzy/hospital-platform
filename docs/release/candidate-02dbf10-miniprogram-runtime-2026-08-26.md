## 本轮修正

选择就诊人页面的“刷新就诊人”是一个会产生患者目录同步副作用的命令。首次目录读取或上一轮同步尚未结束时，按钮原先仍可能收到点击事件，进而创建新的 `listLoadGuard`，淘汰首轮目录响应，让 `loading`、列表和错误态分属于不同请求周期。

现在采用两层门禁：

- WXML 在 `loading`、`syncing` 或 `navigationPending` 任一状态下禁用刷新按钮；
- `onSyncPatients()` 在方法层再次拒绝这三种状态，防止事件重放、无障碍入口或未来其它调用绕过视图属性。

该修正只收紧页面生命周期和命令并发，不改变患者 contract、Provider 请求字段、患者选择规则或同步结果语义。已有单飞、会话代际、owner 目录和临床映射门禁继续生效。
