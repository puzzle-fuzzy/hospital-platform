# 真机证据手机号脱敏门禁审计（2026-08-22）

## 发现

真机三层证据清单允许页面层填写一段 `summary` 文本。此前工具主要通过对象字段名和
15–19 位数字识别身份证、卡号等敏感内容；由于 `summary` 是通用字段名，页面摘要中直接写入
11 位手机号时可能绕过字段名门禁。

这会让验收文档保存不必要的患者联系方式，和日志/证据低敏原则不一致。页面摘要只应记录
“显示已登录”“显示费用列表为空”等业务结果，不应记录姓名、手机号、身份证、卡号或 Provider 原文。

## 修正

- 真机证据审计现在拒绝常见中国移动号段的 11 位手机号；
- 同时拒绝带“手机号/手机号码/mobile/phone”标签的手机号文本；
- 新增带标签和不带标签的回归测试；
- 该门禁只作用于脱敏证据清单，不改变小程序业务 API、患者读模型或旧 Python 服务。

## 验收边界

本修正只提高证据文件的隐私门禁，不代表任何真机业务已验收。真实验收仍须使用当前候选，
并分别取得页面、客户端 HTTP 和服务端同链低敏日志证据。
