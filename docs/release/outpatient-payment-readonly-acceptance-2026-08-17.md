## 4. 当前结论

本次完成了门诊费用只读查询的一个真实账号闭环：

`当前患者选择 → owner-scoped patientId → his-patient 映射 → Provider unpaid/paid 查询 → 合法空列表 → 页面状态展示`

这只能证明空列表、状态参数和页面边界正确，不能宣称以下内容已经完成：

- 有金额记录时的金额单位、费用字段和多条列表展示；
- 第二位就诊人切换后的费用隔离；
- 会话过期、Redis TTL 和失效恢复；
- 费用详情、支付调起、医保授权、结算、退款和 HIS 回写。
