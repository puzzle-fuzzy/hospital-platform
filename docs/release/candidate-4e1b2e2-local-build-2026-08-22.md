## 2. 本轮业务正确性修复

资料页现在区分三种事实：

- `unauthorized` 或 `session-changed`：当前会话失效，清理页面资料并返回登录入口；
- `persistence-temporarily-unavailable` 或普通网络/服务端暂时故障：保留最近一次已确认资料，允许重试；
- `persistence-invalid`：服务端无法确认资料读模型，清空旧资料并阻止保存，但不把数据故障伪装成登录失效。

这避免了两种相反错误：把损坏的个人资料继续展示为当前事实，或把数据库读模型异常误报为“请重新登录”。
页面只清理当前实例的派生显示，不删除平台 token，也不修改服务端资料。
