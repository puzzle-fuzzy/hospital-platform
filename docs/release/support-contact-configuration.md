# 客服公开信息配置边界

更新时间：2026-08-31

## 当前实现

小程序反馈页使用 [`apps/miniprogram/src/services/support-contact.ts`](../../apps/miniprogram/src/services/support-contact.ts) 作为客服电话和工作时间的唯一公开配置来源。热点问题文案、咨询电话弹窗和拨号行为都从该配置读取，避免页面之间出现号码或时段漂移。

这份配置属于随小程序发布的公开展示信息，不是密钥，也不代表在线意见反馈工单已经接通。反馈按钮仍只保留旧端已核对的提示行为，不显示“提交成功”或“已受理”。

## 发布前确认

客服负责人或产品负责人仍需确认以下事实后，才能把当前号码和时段视为正式运营配置：

1. `13835627395` 当前确实属于高平医院对外咨询电话；
2. `工作日：08:00-17:00` 的时段、节假日规则和接听责任人有效；
3. 号码或时段变更由指定负责人提出、审核并随新运行包发布，不能只在某一个页面临时修改；
4. 如果未来接入在线工单，应另立字段、内容安全、受理状态、撤回、保留期限和客服侧权限 contract。
