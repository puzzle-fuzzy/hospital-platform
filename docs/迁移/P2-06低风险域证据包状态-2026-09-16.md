## 3. 统一证据包必须收集的字段

每个域必须绑定同一个候选的 `serverRelease`、小程序 `miniProgramCommit` 和完整 `sourceRevision`，并按业务场景保存：

1. 页面观察时间、页面状态和脱敏截图；
2. 不含查询参数的公共路径、方法、状态码和客户端 `requestId`；
3. 服务端 `traceId`、请求/完成/失败事件、错误分类和耗时；
4. Provider 存在时的有界 `providerRequestId`，或明确记录“不适用”；
5. 成功非空、成功空、未授权、暂时故障、患者切换/会话切换和版本冲突等固定场景；
6. evidence 文件 SHA-256、采集时间窗、操作者和候选版本。

证据中禁止出现 token、授权头、openid/unionid、身份证、完整卡号、手机号、原始 `patId`、Provider 原文、报告正文或带敏感参数的 URL。不要把单元测试日志里的 fixture requestId 复制到真实证据文件。
