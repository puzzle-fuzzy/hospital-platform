# 电子锦旗与表扬信二次验证（2026-09-16）

## 结论

本次重新对照旧端电子锦旗、表扬信的页面入参、客户端接口和旧 Python 服务校验，并验证新端患者上下文与未开放状态。旧服务确实可创建和查询两类记录，但客户端可提交患者、就诊、科室和医护快照，服务端只有当前用户 ID 校验；没有就诊归属、审核公开、脱敏、撤回或幂等 contract。新端保持独立关闭态，不接旧 API、不导入旧历史，也不把旧 `display_type=1` 当审核通过。

### 1.3 旧 Python 校验边界

旧模块在 `/Users/yxswy/Documents/GitHub/hospital/app/api/v1/module_convenience/__init__.py:3-19` 挂载两类路由。schema 接受患者、就诊、科室和医护快照及 `display_type`，只做类型、长度、日期和 0/1 约束，见 `commendatory_letter/schema.py:11-46`、`silk_banner/schema.py:10-44`、公共字段 `base.py:7-28`。
