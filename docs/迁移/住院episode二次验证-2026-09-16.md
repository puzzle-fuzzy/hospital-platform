1. Provider 正式请求/响应、分页排序、超时、拒绝和未知状态样例；
2. 平台 owner/内部 `patientId` 到 Provider 患者的服务端映射，禁止小程序提交 `patId` 或 `patInHosId`；

4. 住院号、病区、床位、医护、诊断、护理、病情、婴儿等字段逐项的公开白名单与脱敏规则；
