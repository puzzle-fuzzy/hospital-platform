## 故障与原因

手机端创建风湿免疫门诊预约成功后，点击微信支付显示“支付未完成，当前订单状态已保留”。
服务器日志确认两次 `POST /api/v1/payments/medical-insurance/business-recovery` 返回
`404 / NOT_FOUND`；未进入自费预支付或微信调起阶段。

当前小程序会先检查同一业务是否已有医保订单。只有业务错误
`medical-insurance-order-not-found` 才允许继续自费支付；通用路由缺失不能作为无订单处理。
旧线上 API artifact 中没有 `business-recovery` 路由或恢复服务方法。
此前正式环境部署只更新医保配置，保留旧程序，遗漏了新小程序与 API 的版本配套校验。

本次只读检查确认目标预约仍为 `booked`，科室匹配，关联医保订单和自费订单均为空。
没有取消预约、重新下单、修改订单状态或代替用户执行付款。
