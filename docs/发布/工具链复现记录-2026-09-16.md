## 3. 可复现发布顺序

在 Node 24.12.0、Bun 1.4.0、pnpm 11.9.0 的同一环境中，下一次小程序候选必须按以下顺序执行并保存输出：

```text
pnpm install --frozen-lockfile
pnpm --filter @hospital/miniprogram build:dev
pnpm --filter @hospital/miniprogram runtime:verify:dev
pnpm --filter @hospital/miniprogram build
pnpm --filter @hospital/miniprogram runtime:verify
```

记录至少包括：`app.json` pageCount、release/development `build-info.json`、构建包文件树 SHA-256、`runtime:verify` 输出、源码 commit、lockfile 版本和构建时间。运行包要交给 DevTools 时，仍须经过 pending 目录和原子发布器；不得把 DevTools 的增量编译结果当作候选来源。
