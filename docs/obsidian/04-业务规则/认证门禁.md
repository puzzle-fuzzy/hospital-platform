# 认证门禁

## 统一规则

```mermaid
flowchart TD
    A[发起请求] --> B{本地 session 存在}
    B -- 否 --> C[执行微信登录]
    B -- 是 --> D[带 session 请求]
    C --> E{登录成功}
    E -- 否 --> F[显示登录失败/重试]
    E -- 是 --> G[写入新会话并重试原请求一次]
    D --> H{响应是否认证失败}
    H -- 否 --> I[交给业务处理]
    H -- 是 --> C
```

## 禁止的行为

- 不把未登录当成空患者。
- 不无限重放请求。
- 不用旧 session 的迟到响应覆盖新 session。
- 不把客户端保存的患者 ID 当作服务端授权证明。
