# 报告短期引用

报告列表返回的不是让客户端永久持有的供应商内部主键，而是服务端生成/校验的短期引用。详情请求必须经过服务端校验，再映射到对应供应商详情接口。

## 保护目标

- 防止跨患者读取报告。
- 防止客户端篡改外部报告 ID。
- 让报告详情引用具有过期时间和明确的数据类型。
- 避免把供应商内部数据结构暴露给小程序。

## 失败行为

引用失效或类型不匹配时，提示刷新报告列表；不要退化为“任意 ID 直接查询”。
