# 报告短期引用

报告列表返回的不是让客户端永久持有的供应商内部主键，而是服务端生成/校验的短期引用。详情请求必须经过服务端校验，再映射到对应供应商详情接口。

## 保护目标

- 防止跨用户、跨患者读取报告。
- 防止客户端篡改外部报告 ID 或把旧页面里的 ID 拼到新患者请求中。
- 让报告详情引用具有过期时间、owner、patient 和明确的数据类型。
- 避免把供应商内部数据结构暴露给小程序。

## 页面侧限制

报告目录只从当前可见列表中按 `viewKey` 找到摘要；摘要没有 `reportId`、点击事件来自旧渲染批次、当前患者已变化或会话代际已变化时，页面拒绝导航到详情。

## 服务端失败行为

引用失效、类型不匹配、患者不归属当前用户或 provider 详情不可用时，返回明确错误并提示刷新/重试；不要退化为“任意 ID 直接查询”。
