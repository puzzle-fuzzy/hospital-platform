# 会话代际与旧响应

小程序请求层维护 session generation/代际。登录恢复或会话替换后，后续请求属于新代际；旧请求即使晚返回，也不能覆盖新会话、当前患者或页面状态。

## 为什么需要

例如：用户切换患者时，旧患者的报告请求尚未返回；此时新患者请求先返回。如果旧响应随后覆盖页面，用户会看到错患者数据。

## 处理规则

- 请求发出时记录 session generation 和患者上下文。
- 响应返回时比对当前 generation/context。
- 不匹配则丢弃旧响应或重新读取，不写入当前页面状态。
