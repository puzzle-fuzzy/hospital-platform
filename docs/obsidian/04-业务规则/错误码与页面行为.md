# 错误码与页面行为

接口错误只有转成页面动作才对用户有意义。当前建议按下面的动作分类记录：

| 错误类别 | 页面动作 | 是否重试 |
| --- | --- | --- |
| 未认证/会话失效 | 登录恢复 | 原请求最多重放一次 |
| 患者缺失 | 打开就诊人选择 | 选择后重新加载 |
| 患者无权限 | 停止请求并提示 | 不盲目重试 |
| 空数据 | 展示空状态 | 用户主动刷新 |
| 供应商暂时失败 | 错误状态和重试 | 有边界地重试 |
| 建设中/迁移 | 展示产品提示 | 不调用不存在的接口 |
| 参数校验失败 | 指向具体字段/动作 | 修正后提交 |

重点：空列表和请求失败必须区分；认证失败和患者为空必须区分。
