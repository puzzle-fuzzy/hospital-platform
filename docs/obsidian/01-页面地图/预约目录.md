# 预约目录

预约不是一次接口完成，而是“医院/科室 → 排班 → 号源/详情 → 写入预约”的浏览链路。当前页面地图主要覆盖目录、排班和记录读取；预约写入要以预约写入契约和运行环境为准。

## 浏览链路

1. 进入页面并确认患者上下文。
2. 获取医院或服务机构列表。
3. 选择科室，读取科室列表。
4. 选择日期/科室，读取排班。
5. 选择可用号源后进入后续预约确认。
6. 提交后回到预约记录，确认结果。
