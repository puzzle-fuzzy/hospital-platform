## 首页统一判断

```mermaid
flowchart TD
    A[点击首页功能] --> B{是否患者范围功能}
    B -- 否 --> C[直接路由或显示建设中]
    B -- 是 --> D{是否有当前患者}
    D -- 否 --> E[打开就诊人选择]
    D -- 是 --> F[带 patientId 进入目标页]
    F --> G[目标页加载接口]
    G --> H{会话是否失效}
    H -- 是 --> I[登录恢复后重放一次]
    H -- 否 --> J[渲染成功或按错误码提示]
```
