# 首页 · 服务栅格未开放功能

首页服务栅格固定为“门诊、住院、便民”三组，每组 5 项，共 15 个可见入口。当前源码的每个项目都配置了固定 action：已开放项目进入对应页面，未开放项目进入 `FeatureKey` 状态页，不再落入默认“该服务正在建设中”分支。

## 与顶部/右侧入口的区别

- 顶部“门诊病历”和服务栅格里的同名项目都走明确 `medical-record` 分支，状态页文案和阻塞类型保持一致。
- 右侧“智能导诊”和悬浮导诊不是服务栅格项；它们分别进入固定 `guide` 或 `smart-customer` 状态页。
- 服务栅格没有住院、健康百科等对应 API，不能从视觉入口推导出接口存在。
