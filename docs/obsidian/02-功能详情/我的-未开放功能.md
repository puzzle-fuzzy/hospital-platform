# 我的 · 未开放功能

“我的”页面菜单中有 9 个菜单项；其中只有我的挂号、爽约记录和意见反馈存在可进入页面，个人资料/家庭成员是头部卡片入口。其余项目在 action 分支中明确返回迁移或授权提示。

| 入口 | action | 点击结果 | 接口 |
| --- | --- | --- | --- |
| 我的问诊 | `consultation` | “我的问诊功能正在迁移中” | 无 |
| 门诊病历 | `medical-record` | “门诊病历正在迁移中” | 无；不能复用报告接口 |
| 电子导诊单 | `electronic-consultation` | “电子导诊单功能正在迁移中” | 无 |
| 我的医生 | `doctor` | “我的医生功能正在迁移中” | 无 |
| 智能客服 | `smart-customer` | “智能客服功能正在迁移中” | 无 |
| 医保电子凭证 | `insurance` | “需要独立授权，当前暂未开放” | 无；不能绕过平台直连 |

## 特殊代码分支

`my.ts` 中存在 `outpatient-payment` 分支，可走患者门禁进入门诊费用页，但该 action 当前不在可见的 `MY_MENU_SECTIONS` 菜单数据中。因此它是代码预留入口，不应在用户可见功能数量中统计为一个当前菜单项。

底部导航：第 0 项重新打开首页，第 3 项保持“我的”，第 1/2 项显示迁移提示。
