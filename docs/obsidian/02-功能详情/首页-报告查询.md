# 报告查询

## 用户触发

首页顶部报告入口、右侧报告入口或“我的”中的报告入口。

## 逻辑

1. 患者门禁通过后进入报告目录。
2. 调用 `GET /reports` 获取当前患者的报告摘要列表。
3. 用户点击报告项，前端带报告引用进入详情页。
4. 服务端校验短期引用和患者归属，再调用对应的检验/检查详情适配器。
5. 成功后渲染详情；引用失效时要求刷新列表，不直接把任意外部 ID 交给供应商。

接口：[[03-接口目录/报告-目录与详情|报告目录与详情]]。

规则：[[04-业务规则/报告短期引用|报告短期引用]]、[[04-业务规则/患者门禁|患者门禁]]。
