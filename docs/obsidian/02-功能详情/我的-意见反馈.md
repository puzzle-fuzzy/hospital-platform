# 我的 · 意见反馈

## 当前入口行为

“我的”点击意见反馈会导航到 `/pages/feedback/feedback`。反馈页目前只有静态热点问题、客服电话和折叠展开，没有在线工单提交 API。

| 用户动作 | 实际代码行为 | 是否产生后端写入 |
| --- | --- | --- |
| 点击意见反馈 | 进入反馈页 | 否 |
| 点击“意见反馈”操作区 | Toast：“跳转到意见反馈页面” | 否，跳转代码目前被注释 |
| 点击咨询电话 | 弹出 `13835627395`、工作日 08:00–17:00；确认后 `wx.makePhoneCall` | 否 |
| 点击热点问题 | 同一时间展开/收起一条静态 FAQ | 否 |

## 不能误读的地方

- 当前没有 `POST /feedback`、表单字段、内容安全校验、工单状态或提交成功回执。
- 静态 FAQ 不是服务端配置，也不是医疗诊断结论。
- “页面存在”只能说明导航和展示存在，不能标记为完整反馈闭环。
