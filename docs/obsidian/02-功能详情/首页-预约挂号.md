# 首页 · 预约挂号

## 用户触发

点击首页顶部“预约挂号”或右侧医院列表入口。

## 实际逻辑

```mermaid
flowchart TD
    A[点击预约挂号] --> B{当前患者存在}
    B -- 否 --> C[进入就诊人选择]
    B -- 是 --> D[进入预约目录]
    D --> E[读取医院/科室]
    E --> F[读取排班]
    F --> G{是否有可用排班}
    G -- 否 --> H[空状态/换日期或科室]
    G -- 是 --> I[展示可预约号源]
    I --> J[进入确认或写入流程]
```

## 接口链

- 目录：[[预约-目录与排班|预约目录与排班]]
- 记录：[[预约-记录|预约记录]]
- 公共前置：[[认证门禁|认证门禁]]、[[患者门禁|患者门禁]]

## 不能误读的地方

- `GET /appointments/departments`、`GET /appointments/schedules` 说明目录/排班读取链存在；它们不是预约写入成功的证明。
- 预约写入涉及供应商和支付/确认边界，具体以 [预约写入契约](../../appointment-write-contract-v1.md) 和运行时接口为准。
