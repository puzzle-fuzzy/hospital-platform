# 首页 · 互联网医院/关注入口

首页有两类容易混淆的“互联网医院”入口：顶部快捷入口的 `hospital-list`，以及轮播图的 `follow`。前者当前复用预约目录加载，后者打开公众号静态说明页；两者都不是完整的互联网医院在线问诊接口链。

## 判断

| 情况 | 行为 |
| --- | --- |
| 顶部“互联网医院” | 进入预约目录加载逻辑；动态机构和外部互联网医院尚未开放 |
| 轮播图点击 | 进入静态公众号说明页 |
| 用户未关注公众号 | 展示关注说明 |
| 用户期待在线问诊 | 当前源码没有从此入口证明完整问诊闭环 |
| 静态入口不可打开 | 按页面错误提示处理，不影响患者主链路 |
