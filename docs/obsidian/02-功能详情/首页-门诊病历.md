# 首页 · 门诊病历

当前点击路径存在，但业务页面仍处于迁移/建设状态。用户点击后得到迁移提示或建设中提示；当前源码没有可确认的门诊病历读取接口链。

## 结论

- 不应把菜单文案当作已交付功能。
- 不应为该入口虚构接口。
- 以后接入接口时，应新增独立的接口目录、数据状态字典和错误行为说明。
