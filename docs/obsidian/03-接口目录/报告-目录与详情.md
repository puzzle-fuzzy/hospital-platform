# 报告 · 目录与详情

| 接口 | 用途 | 关键边界 |
| --- | --- | --- |
| `GET /reports` | 读取当前患者报告摘要 | 必须有患者上下文 |
| `GET /reports/:reportId` | 读取报告详情 | 校验短期引用、患者归属和详情类型 |

## 服务端实际链

- 列表：`ReportService.list` → provider `listReports` → 规范化 → 生成短期 report reference。
- 详情：`ReportService.detail` → 校验 reference → 按实验室/检查类型调用详情适配器 → 规范化结果。

见：[[04-业务规则/报告短期引用|报告短期引用]]。

源码：[reports/index.ts](../../../apps/api/src/modules/reports/index.ts)。
