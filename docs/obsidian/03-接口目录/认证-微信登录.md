# 认证 · 微信登录

## 请求链

```mermaid
sequenceDiagram
    participant U as 小程序
    participant W as 微信 wx.login
    participant C as api-client
    participant A as API AuthService
    participant P as 身份供应商
    U->>W: 获取临时 code
    W-->>U: code
    U->>C: login(code)
    C->>A: POST /auth/wechat
    A->>P: exchangeCode(code)
    P-->>A: 外部身份
    A-->>C: session/access 信息
    C->>C: 写入会话并增加 session generation
```

## 关键判断

- 没有 code、code 过期或供应商失败：不写入半成品会话。
- 新登录成功后，旧请求不能覆盖新会话，见 [[会话代际与旧响应|会话代际]]。
- 认证失败应返回登录动作，而不是把认证错误误报成患者为空。
