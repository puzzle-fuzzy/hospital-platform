# 预约 · 记录

预约记录被首页“我的挂号”、我的页面“我的挂号”和“爽约记录”复用。

## 返回后的页面分支

| 数据/状态 | 页面行为 |
| --- | --- |
| 有记录 | 按状态分组或筛选 |
| 空列表 | 展示暂无预约，并保留刷新/去预约入口 |
| 认证失效 | 登录恢复后重试一次 |
| 患者已切换 | 丢弃旧患者响应，按新患者重新加载 |
| 供应商错误 | 展示错误状态，不伪装为空列表 |

源码：[appointments/index.ts](../../../apps/api/src/modules/appointments/index.ts)。
