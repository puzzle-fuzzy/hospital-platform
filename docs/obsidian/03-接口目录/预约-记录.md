# 预约 · 记录

完整路径：`GET /api/v1/appointments/records`。它被“我的挂号”和“爽约记录”复用；后者在同一份预约记录读模型上做 `missed` 状态筛选，没有独立爽约接口。

## 查询参数

| 参数 | 必填 | 取值/说明 |
| --- | --- | --- |
| `patientId` | 是 | 当前用户已绑定患者 |
| `scope` | 否 | `online` 或 `all`，页面两个 Tab 对应两个范围 |
| `startDate` | 否 | 日期窗口开始 |
| `endDate` | 否 | 日期窗口结束 |

## 返回和页面分支

返回预约记录数组和 `total`。记录可包含科室、医生、工作日、时间、地点、序号及状态：`scheduled`、`cancelled`、`completed`、`missed`、`stopped`、`substituted`、`registered`、`unknown`。

| 数据/状态 | 页面行为 |
| --- | --- |
| 有记录 | 根据 Tab 或爽约页面规则过滤和翻译展示 |
| 空列表 | 展示暂无预约/暂无爽约记录，不当作服务异常 |
| 认证失效 | 走登录恢复或显示可重试错误 |
| 患者已切换 | 丢弃旧患者响应，按新患者重新加载 |
| 供应商错误 | 展示错误状态，不伪装为空列表 |
| 点击记录 | 当前只有“详情暂未开放”提示，没有预约详情接口 |
