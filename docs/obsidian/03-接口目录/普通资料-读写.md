# 普通资料 · 读写

个人资料使用当前 Bearer 用户上下文；它和患者绑定、报告、门诊费用属于不同数据边界。完整路径为 `/api/v1/me/profile`。

## 接口契约

| 方法 | 路径 | 请求 | 返回/行为 |
| --- | --- | --- | --- |
| `GET` | `/me/profile` | 无 body | 返回当前用户资料和 `version` |
| `PUT` | `/me/profile` | 必填 `version`；可选 `displayName`、`gender`、`age`、`email` | 按当前用户写入，返回服务端 canonical 资料 |

校验规则：

- `version` 为整数，用于并发版本控制。
- `displayName` 不能是空白名称。
- `gender` 只能是 `male`、`female`、`unknown`。
- `age` 为 `0–150` 或 `null`。
- `additionalProperties=false`，不允许把 `userId`、患者 ID、身份字段或旧端扩展字段混入 PUT。

## 页面调用判断

- 读取：资料页进入/重新显示时调用 GET，响应必须属于当前请求代际。
- 更新：先确认最近读取的 version 仍属于当前会话，再 PUT；快速连点由页面层拦截，服务端继续负责版本冲突。
- 成功：使用服务端返回的 canonical 快照；失败：保留输入，按错误码显示字段错误、重试或重新登录。
