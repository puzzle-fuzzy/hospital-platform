# 预约 · 目录与排班

| 接口语义 | API 服务入口 | 用途 |
| --- | --- | --- |
| 科室目录 | `GET /appointments/departments` | 展示医院/科室 |
| 排班目录 | `GET /appointments/schedules` | 按患者、科室、日期读取排班 |
| 医院列表 | 由预约模块提供 | 首页医院列表和预约入口复用 |

## 统一判断

- 未认证：返回认证错误，前端进入登录恢复。
- 无当前患者：前端在进入页前拦截，服务端仍不能省略患者范围校验。
- 无排班：返回可识别的空结果，不当作系统异常。
- 供应商不可用：保留错误上下文，不能返回虚构号源。
