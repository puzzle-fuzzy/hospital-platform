# 门诊费用 · 记录

门诊费用读取由 outpatient-payments 模块提供，真实路径是 `GET /payments/outpatient/records`，查询患者的待缴/已缴等记录；当前页面入口在首页，个人中心当前没有该菜单项。

## 重要边界

- `GET` 列表只是读取费用状态。
- 进入微信支付后，预下单、签名和支付结果是独立流程。
- 代码图中同名 `list` 方法可能出现候选关系，实际调用以 [outpatient-payments/index.ts](../../../apps/api/src/modules/outpatient-payments/index.ts) 的依赖对象为准。
