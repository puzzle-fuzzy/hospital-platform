# 门诊费用 · 记录

完整路径：`GET /api/v1/payments/outpatient/records`。这是只读费用记录接口，不能把它当作支付下单接口。

## 请求

| 参数/头 | 要求 |
| --- | --- |
| Bearer | 必须是当前登录用户 |
| `patientId` | 必填，服务端再次校验患者归属 |
| `status` | 必填，只能是 `unpaid` 或 `paid` |
| `idempotency-key` | 可选，用于请求上下文；不是支付成功凭证 |
| `x-request-id` | 可选追踪信息 |

示例语义：`GET /api/v1/payments/outpatient/records?patientId=p_xxx&status=unpaid`。

## 返回

记录包括 `recordId`、`status`、科室/医生、`billDate`、`amountFen`、明细项和 `total`。页面把 `amountFen` 格式化为金额，并按 `status` Tab 本地展开当前响应。

## 重要边界

- `GET` 只读取费用状态；它不会创建订单、预下单、拉起微信或改变已缴状态。
- 待缴/已缴记录点击目前都只是迁移提示。
- 服务未配置或患者没有缴费映射时，页面会清空旧费用读模型，不能保留上一患者金额。
- 进入支付要转到 [[微信支付-代码边界]] 的独立订单链路。
