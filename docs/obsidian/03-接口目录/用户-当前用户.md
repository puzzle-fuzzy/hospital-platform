# 用户 · 当前用户

这是页面进入阶段的用户上下文读取接口。它确认当前 session 对应的用户，不负责选择患者。

## 与患者接口的边界

`/me` 成功只说明“当前用户已识别”；之后仍需要 [[03-接口目录/患者-列表|GET /patients]] 读取患者列表。
