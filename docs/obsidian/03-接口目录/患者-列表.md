# 患者 · 列表

完整路径：`GET /api/v1/patients`。

## 用途和响应

读取当前登录用户已经绑定的就诊人，为首页、我的、就诊人选择、报告、预约记录和门诊费用建立患者上下文。返回 `PatientListResponse`：`items[]` 和 `total`。

每个患者当前可见字段包括：

- `id`：供当前会话内后续查询使用的不透明患者标识。
- `displayName`、`relationship`：关系值为 `self|spouse|child|parent|other|unknown`。
- `cardNumberMasked`：脱敏卡号。
- `source`：`hospital-his|legacy-record`。
- `clinicalAccess`：`ready|unavailable`。

## 入口与判断

1. 必须先通过 [[认证门禁]]。
2. 服务端按当前 principal 查询，不接受客户端任意 `userId` 作为权限替代。
3. 空数组表示当前用户没有绑定患者，不等价于请求失败。
4. 只有 `clinicalAccess=ready` 的患者可以成为当前患者并进入患者范围业务。
5. 患者变更、同步完成或会话代际变化后，页面要重新建立当前患者，而不是沿用旧 ID。

## 页面调用

首页/我的会在进入或显示时读取它；选择页还可能先调用 [[患者-同步]]，再重新读取列表。报告、挂号和费用页错误重试时会重新确认 owner + patient，避免旧列表继续显示。
