# 患者 · 列表

## 用途

读取当前登录用户已经绑定的就诊人，并为首页、我的、就诊人选择页提供当前患者上下文。

## 入口与判断

1. 必须先通过 [[04-业务规则/认证门禁|认证门禁]]。
2. 服务端按当前 principal 查询，不接受客户端任意 userId 作为权限替代。
3. 空数组表示当前用户没有绑定患者，不等价于请求失败。
4. 患者变更后页面需要刷新列表并更新 currentPatientId。

源码：[patients/index.ts](../../../apps/api/src/modules/patients/index.ts)、[patient-navigation.ts](../../../apps/miniprogram/src/services/patient-navigation.ts)。
