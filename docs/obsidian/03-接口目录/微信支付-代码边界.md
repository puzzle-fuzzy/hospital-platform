# 微信支付 · 代码边界

## 当前可确认的调用链

```text
页面点击支付
  → api-client.requestWechatPrepay
  → 服务端支付预下单接口
  → 前端 toWechatPaymentParams
  → uni.requestPayment 拉起微信支付
```

`uni.requestPayment` 负责拉起支付，不负责创建预支付订单，也不应被当作业务接口本身。

## 需要独立验证的内容

- 微信商户号、AppID、API v3 密钥和回调是否在当前环境配置。
- 预下单返回的 `prepay_id` 是否真实可用。
- 支付回调验签、幂等写回和订单最终状态是否形成闭环。
- 自费、医保或混合支付是否有独立状态机。

源码：[api-client.ts](../../../apps/miniprogram/src/services/api-client.ts)、[payments module](../../../apps/api/src/modules/payments/index.ts)。
