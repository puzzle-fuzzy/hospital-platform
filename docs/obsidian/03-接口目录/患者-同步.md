# 患者 · 同步

## 用途

把用户通过二维码/外部身份获得的就诊人信息同步到当前用户的患者绑定关系中。

## 服务端链

`PatientService.sync` → 外部患者目录 `listByIdentity` → 患者数据规范化 → 绑定关系写入/冲突检查 → 返回可供页面展示的患者结果。

## 风险判断

- 同步必须绑定当前 principal，不能只相信客户端传入的患者标识。
- 同一外部患者已经绑定其他用户时，应走冲突分支，不静默转移。
- 同步失败不能删除原有患者列表。
