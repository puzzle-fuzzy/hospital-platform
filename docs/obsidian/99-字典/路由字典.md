# 路由字典

## 首页入口

| action | 入口/位置 | 实际页面或行为 |
| --- | --- | --- |
| `appointments` | 顶部预约 | 先到固定医院展示页，再到预约目录 |

| `reports` | 右侧报告查询 | 患者门禁后到报告目录 |
| `appointment-records` | 门诊服务栅格 | 患者门禁后到预约记录 |
| `patient-select` | 就诊人绑定/患者卡 | 就诊人选择页 |
| `hospital-navigation` | 便民栅格 | 本地静态地图页 |
| `medical-record` | 顶部病历 | 迁移 Toast；不复用报告路由 |
| 未配置 action | 其余服务栅格 | 建设中 Toast |
