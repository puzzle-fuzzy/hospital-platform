## 首页 action 证据

| action | 点击位置 | 真实行为 |
| --- | --- | --- |
| `appointments` | 顶部预约 | 登录门禁后进入 `hospital-list` |
| `outpatient-payment` | 顶部缴费 | 患者门禁后进入费用页 |
| `hospital-list` | 顶部互联网医院 | 实际复用预约入口，不是动态互联网医院列表 |
| `follow` | 三张轮播图 | 进入静态公众号说明页 |
| `reports` | 右侧报告查询 | 患者门禁后进入报告目录 |
| `guide`/`companion` | 右侧快捷入口 | 未配置 action，建设中 Toast |
| `medical-record` | 顶部/服务栅格 | 门诊病历迁移 Toast，不复用报告路由 |
| `appointment-records` | 服务栅格 | 患者门禁后进入预约记录 |
| `hospital-navigation` | 便民栅格 | 进入本地静态地图页 |
| 其他服务 action | 服务栅格 | 默认建设中 Toast |
| 底部 tab 0/3 | 首页/我的 | 首页无动作；我的进入 `/pages/my/my` |
| 底部 tab 1/2 | 服务/消息 | 迁移中 Toast |

## 我的 action 证据

| action | 真实行为 |
| --- | --- |
| `profile` | 认证后进入 `/pages/profile/profile` |
| `patient-select` | 进入患者选择 |
| `appointment-records` | 患者门禁后进入预约记录 |
| `missed-appointments` | 认证后进入爽约页，再由页面读取患者记录 |
| `outpatient-payment` | 代码有患者范围分支，但当前不在可见菜单中 |
| `feedback` | 进入静态反馈页 |
| `medical-record` | 迁移 Toast |
| `consultation`、`electronic-consultation`、`doctor`、`smart-customer`、`insurance` | 迁移/未开放提示 |

## 不能只看按钮得出的事实

- 页面能导航不代表对应 API 已配置；组合根和 service gate 还要一起看。
- 预约排班能展示不代表有预约写入。
- 费用记录能读取不代表支付已接入。
- 报告摘要有 `reportId` 才能进入详情，切换患者/会话后旧引用不能继续消费。

请求服务集中在 [dashboard-service.ts](../../../apps/miniprogram/src/services/dashboard-service.ts) 和 [api-client.ts](../../../apps/miniprogram/src/services/api-client.ts)。
