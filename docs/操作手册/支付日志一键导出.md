# 3090 支付日志一键导出

## 两个功能

文档提供两个独立的导出功能，最终都只返回一个可打开的 `daily-index.md`：

1. **全日支付索引**：导出指定中国标准时间日历日内识别到的每一笔支付，按订单列出开始时间、实际调用接口以及每个接口的入参和返回 JSON。
2. **最新一笔支付索引**：在指定时间窗口内按支付开始时间选取最后一笔，只导出这一笔的接口和 JSON，适合快速查看刚刚发生的支付。

两个功能都保留独立 invocation（包括重试），并对 6201/6202 使用可用的业务明文；原始 Provider 报文仅写入受控文件用于核验。最新一笔模式会忽略后台查单重试生成的孤立记录，并自动向前回看 2 分钟，避免指定起点恰好切掉 1101 等首个请求。

## 默认用法

在仓库根目录执行：

```bash
pnpm payment:day
```

脚本按中国标准时间的“今天”计算窗口，通过当前 3090 SSH 跳板读取：

- `hospital-platform-api-v2.service`
- `hospital-platform-worker-v2.service`

远端命令固定使用 `journalctl --all -o json --no-pager`。默认连接参数为
`ps@10.0.0.3`、跳板 `meiyi.pro`、密钥 `~/.ssh/aliyun-3090`。

## 结果

脚本只需要关注输出目录中的 `daily-index.md`：

1. 先列出当天识别到的每笔支付订单和开始时间；
2. 每笔订单下列出实际观察到的接口；
3. 每个接口提供独立的 `request.json` 与 `response.json`；
4. 同一接口的重试按独立 invocation 保留，不合并成一条；
5. `6201` / `6202` 若有完整的 logical FSI 原文，`request.json` / `response.json`
   直接展示业务明文；嵌套 JSON 字符串（例如 `passthrough_response_content`）也会
   展开为可读对象，不再显示成片的反斜杠转义；
6. 支付完成后的自费查单会产生新的 `traceId`。脚本会通过 API journald 中两个
   精确的 GET 路由，把它重新关联到原支付订单：
   `/api/v1/payments/appointments/:appointmentId/self-pay` 与
   `/api/v1/payments/outpatient/records/:recordId/self-pay`。因此查单过程中实际调用的
   `2.27.2.29`、`2.6.65.15`、`2.6.65.5` 及其重试不会再因为 trace 变化而漏出索引；
7. 索引顶部同时显示请求窗口、实际采集窗口、原始日志最后观测时间、订单数、
   已关联接口数、查单 trace 桥接数、歧义/缺证据未归属数和原始报文完整性。每笔
   订单还会显示最后观测时间、业务状态、接口数及该笔查单 trace 数；同一接口跨
   trace 重试会标成“第 1/N 次、……、第 N/N 次”。

`COMPLETE_FOR_ALL_CORRELATED_INVOCATIONS` 只表示已经通过订单标识或上述受信
查单路由关联到订单的调用，其请求、返回和 chunk 均齐全，并且日志中存在的字节
长度/摘要元数据核验通过。它不表示采集截止时间之后没有新调用，也不表示无法安全
关联的调用不存在。查单时间早于候选订单、缺少查询附近的明确结算事件，或资源 ID
同时命中多笔订单且缺少唯一结算证据时，脚本保持未归属并在索引/manifest 明确计数，
不会按时间最近擅自串单。

原始 journald、chunk 校验信息、FSI 补充原文和归档同时保存在同一受控目录中，
用于核验但不作为日常展示内容。`request-body.raw` / `response-body.raw` 保留
Provider 正文的原始字节。目录权限为 700，文件权限为 600；脚本标准输出只返回
`daily-index.md` 路径，不回显患者凭证、请求头或原始报文。

## 常用参数

```bash
# 指定某一天
pnpm payment:day -- --date 2026-09-17

# 只导出当天开始时间最新的一笔支付
pnpm payment:last

# 最新一笔也可以离线使用已有 journald 快照
pnpm payment:last -- --date 2026-09-17 \
  --input-file /private/tmp/payments-day-20260917/journal.jsonl

# 只用已下载的 journald 离线重跑，不连接 3090
pnpm payment:day -- --date 2026-09-17 \
  --input-file /private/tmp/payments-day-20260917/journal.jsonl

# 认证由 ssh agent 或 ~/.ssh/config 提供
pnpm payment:day -- --ssh-key /path/to/key

# 远端 journalctl 需要免密 sudo 时
pnpm payment:day -- --remote-sudo
```

如需更换服务器或跳板，优先使用 `--ssh-target`、`--ssh-jump` 或对应的
`PAYMENT_LOG_SSH_*` 环境变量；不要把密钥、医保凭证或导出目录提交到 Git。
