# 生产链路拓扑（实测版）

> 实测时间：2026-09-03，方法：对 `3090-local` 与 `meiyi.pro` 的只读核查（nginx 配置、监听端口、进程、git 状态）。
> 事实来源与更完整的链路说明见 [`../docs/提供商接入/2026-09-03-旧端链路流向图与生产拓扑.md`](../docs/提供商接入/2026-09-03-旧端链路流向图与生产拓扑.md)。
> 本文只描述拓扑与边界，不包含任何凭据值；环境：测试环境（`test-hp.meiyi.pro`）。

## 1. 拓扑

```
微信小程序
  │ HTTPS
  ▼
阿里云中转 meiyi.pro (8.130.127.184)
  ├─ test-hp.meiyi.pro  ── /api/v2/* ── VPN ──► 10.0.0.3:18081（新 Elysia API，3090）
  │                       └ /api/v1/* ── autossh 隧道 ──► 3090:8001（旧 Python，test-v3）
  ├─ gpsrmyy.meiyi.pro  ── nginx ──► localhost:7112（Java 拦截器）
  │        · 新 API 的 ZHONGYANG_BASE_URL 即指向这里（已验证可用）
  │        · 拦截器内置“获取叫号信息并推送”定时任务（每 7–20 秒轮询 HIS）
  │        · forward 协议：POST /forward {method, base_url, path, headers, body}
  │            base_url → http://124.164.248.83:50080（医保 FSI，通道层 envelope）
  │                     → http://124.164.248.83:56380（众阳 org/HIS，6201/6202）
  │                     → https://test-receiver.wecity.qq.com（腾讯医保授权）
  ├─ MySQL :3306（旧系统库）
  └─ Redis（实测无监听：故障态，仅影响旧系统）

3090（192.168.112.172 / VPN 10.0.0.3）
  ├─ 新 API 10.0.0.3:18081 —— MySQL :3306、Redis 127.0.0.1:6379（均在 3090 本机，与旧系统隔离）
  └─ 旧 Python 0.0.0.0:8001（test-v3 分支 + 4 个未提交文件，退役前须收割）
```

## 2. 运维边界与风险

| 风险 | 说明 | 建议 |
| --- | --- | --- |
| 中转机单点 | 所有 Provider 流量（众阳/FSI/wecity）经 meiyi.pro 的 nginx + 拦截器；该 Java 组件不在本仓库版本控制内 | 最低限度加 nginx `access.log` 错误率告警与 `:7112` 存活探针；变更拦截器前先快照 |
| 叫号推送藏在拦截器 | 旧“实时叫号”实为中转机轮询 HIS，不是 WebSocket | 新端 E 批次按“服务端轮询→受控推送”设计，勿复刻到拦截器 |
| forward 鉴权 | 旧代码硬编码 `Bearer main-token`；新仓库用 `MBS_FORWARD_AUTHORIZATION_TOKEN` | 该 token 在中转侧如何轮换目前无人负责，切换 F 批次前明确 owner |
| 双隧道并存 | `/api/v1`（autossh→旧）与 `/api/v2`（VPN→新）同域共存 | 旧服务退役时同步清理 autossh 与 nginx 旧 location |
| 旧服务分叉 | test-v3 有 4 个未提交修复（含“允许空工作站ID”） | 退役前 `git diff` 收割归档到本仓库证据目录 |
| 图片域名白名单 | 新增医生照片走 `<image>` 直连 OSS | 上线前在小程序后台登记 downloadFile 域名 |

## 3. 与本仓库配置的对应

| 环境变量 | 实测值（测试环境） | 说明 |
| --- | --- | --- |
| `ZHONGYANG_BASE_URL` | `https://gpsrmyy.meiyi.pro` | 新 API 众阳通道，经拦截器 |
| `MBS_FORWARD_BASE_URL` | `http(s)://...`（1101 通用 FSI） | 1101 授权解析的 forward 体内部 base_url；API 到 relay 仍必须 HTTPS，与 `MBS_FORWARD_BASE_URL_6201` 分开 |
| `MBS_FORWARD_BASE_URL_6201` | `http(s)://...`（6201/6202/6301 FSI） | 6201/6202/6301 严格加密 FSI 的 forward 体内部 base_url；具体地址和密钥不写入仓库 |
| `MBS_USER_QUERY_BASE_URL` | `https://test-receiver.wecity.qq.com`（测试） | 授权码解析目标；服务端通过 relay 调用，不能由小程序直连 |
| `DATABASE_URL` / `REDIS_URL` | 3090 本机 | 新系统独立库，冷启动隔离 |
