# 医保结算页独立演示小程序

这是从 `apps/miniprogram` 的 `outpatient-medical-settlement` 页面抽出的独立微信小程序演示工程。

## 使用方式

1. 用微信开发者工具导入本目录：`apps/miniprogram-settlement-demo`
2. 选择“公众号/小程序”登录方式；没有真实 AppID 时可使用测试号或游客模式。
3. 入口页就是医保结算页，页面会先展示加载态，再自动填充本地假数据。

`project.config.json` 为了能在当前开发者工具直接预览，暂时复用了原工程的合法 AppID；这是本地预览配置，不代表这个演示工程可以直接上传为正式版本。若要注册成真正独立的小程序，请在开发者工具中替换为新小程序 AppID。

## 演示数据

- 医院：高平市人民医院
- 费用总额：41.00 元
- 医保基金支付：0.00 元
- 个人账户支付：40.00 元
- 其他抵扣金额：0.00 元
- 现金支付：1.00 元

点击“去支付”完成演示后，再点击“演示已完成”会进入原小程序同款支付成功页。成功页保留原页面的“查看门诊详情”和“返回首页”按钮，按钮行为在本地演示工程中做了安全替代，不会请求接口，也不会调用真实支付能力。
